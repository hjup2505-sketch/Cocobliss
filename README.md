## 🚀 How to Preview & Run the Website Locally

You can preview the website in **two very easy ways**:

### Method 1: The Built-in Node Server (Recommended)

1. Open your terminal or PowerShell inside the `c:\Chocobliss` folder.
2. Run the command:
   ```bash
   node server.js
   ```
   *(or run `npm start`)*
3. You will see:
   ```text
   🍫 Cocobliss Chocolate Artisan Website
   ✨ Local preview running at: http://localhost:3000
   ```
4. Click or open **[http://localhost:3000](http://localhost:3000)** in your favorite web browser (Chrome, Edge, Safari, Firefox).
5. To stop the server at any time, press `Ctrl + C` in the terminal.

---

### Method 2: Direct Double-Click (Zero Setup Required)

Because the project is built with clean, modern HTML5, CSS3, and Vanilla JavaScript, you don't even need a server:
1. Open Windows File Explorer and navigate to `C:\Chocobliss`.
2. Double-click **`index.html`**.
3. It will immediately open in your default browser!
